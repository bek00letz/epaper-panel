How to flash in Home Assistant
  1. Open the ESPHome add-on → click New Device → name it and pick ESP32-S3 → click Skip.
  2. Click Edit on the newly created device card, replace the file with the YAML above, and click Install (use USB-C for the first flash; updates after that are wireless OTA).
  3. When Home Assistant discovers the panel under Settings → Devices & Services, click Configure and paste the API encryption key above.
