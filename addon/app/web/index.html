🌙 Night / Quiet Hours (Zero-Ghosting Deep Idle)
Status: Disabled (24/7 normal refresh & rotation)
E-paper is bistable and holds its last image cleanly with 0 mW power and zero backlight glow. When Night / Quiet Hours is enabled and active:
  • Zero screen flashes: Automatic page rotation and periodic full-screen e-ink refreshes pause so the display never flashes in a dark room or wears the e-ink film while nobody is looking.
  • Zero Wi-Fi polling: The panel skips background HTTP strip downloads while Quiet Hours is active.
  • Instant manual wake: Pressing any physical button on the CrowPanel or turning your IKEA BILRESA remote still flips pages immediately on demand.

How to flash in Home Assistant
  1. Open the ESPHome add-on → click New Device → name it and pick ESP32-S3 → click Skip.
  2. Click Edit on the newly created device card, replace the file with the YAML above, and click Install (use USB-C for the first flash; updates after that are wireless OTA).
  3. When Home Assistant discovers the panel under Settings → Devices & Services, click Configure and paste the API encryption key above.
